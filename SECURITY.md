# Security Policy

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub private vulnerability reporting](https://github.com/ayaka-notes/ayakaleaf-pro/security/advisories/new)
or by email to ayaka@outlook.in.

Please include the version or image tag, steps to reproduce, and the impact.

## Supported versions

Fixes go into `server-pro` and the latest release.
