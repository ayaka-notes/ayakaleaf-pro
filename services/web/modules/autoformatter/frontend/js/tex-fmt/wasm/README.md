# tex-fmt

The files in this directory are:

- `tex_fmt_bg.wasm`: [tex-fmt](https://github.com/WGUNDERWOOD/tex-fmt) v0.5.7 compiled to WebAssembly, via the [build.sh](../build.sh) script.
- `tex_fmt.js`: a JavaScript wrapper for the WebAssembly module, generated by wasm-bindgen.
- `tex_fmt.d.ts`: types for the exports from the JavaScript module, generated by wasm-bindgen.
